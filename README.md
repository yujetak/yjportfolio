## 💻 Local Setup & Run (로컬 실행 방법)

본 프로젝트는 빠르고 가벼운 빌드 도구인 **Vite**를 기반으로 개발되었습니다.

### 1. 의존성 패키지 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```
개발 서버가 시작되면 브라우저에서 `http://localhost:5173`으로 접속할 수 있습니다.

### 3. 프로덕션 빌드 및 정적 파일 생성
```bash
npm run build
```
빌드가 성공적으로 완료되면 최적화된 파일들이 `dist/` 폴더 내에 생성됩니다.
